## 实现

- 共享设置列表采用可选 presentation= settings 模式，其他 SchemaForm 页面保持默认布局。
- 环境配置六类导航，AI 高级设置三类导航；搜索跨分类匹配名称、键、说明和嵌套路径。
- 简单字段直接编辑；默认值仅展示，不自动写入。恢复默认、未设置和 null 保持独立语义。
- 复杂结构使用独立弹窗草稿，取消不改页面；应用仅改草稿，嵌套对象在弹窗内部折叠。
- 运行值保持后端提供和只读，草稿修改、保存未生效及环境覆盖分别显示。
- AI 请求参数带单位，Gemini 阈值选择器、混合工具开关、调试日志三个开关直接操作；未知参数和包含点号的键保留。
- 页面统一保存、撤销与修改计数，校验覆盖全部分类，错误定位到所属分类。
- 清理已不用的环境卡片及 AI 高级卡片样式。
